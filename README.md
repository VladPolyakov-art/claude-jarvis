# Jarvis — голосовой напарник для Claude Code

> **EN:** A local, Russian-speaking voice companion for [Claude Code](https://claude.com/claude-code) on macOS. It reads out what Claude just did, asks you Claude's questions, sends your spoken answer back into the session, routes messages between chats by name and pings you when something needs your eyes. Fully local: Silero TTS · Whisper (MLX) · Ollama.

Claude закончил шаг — Jarvis в двух фразах рассказывает, что сделано, задаёт вопрос, если он есть, и передаёт твой ответ голосом обратно в ту же сессию. Claude идёт работать дальше, а ты не отрываешься от своих дел.

Всё локально, без облака: голос — **Silero** / **Piper**, слух — **Whisper large-v3-turbo на MLX**, мозг для пересказов — **Ollama (qwen3:4b-instruct)**. Работает и в десктоп-приложении Claude, и в терминале.

## Установка

macOS на Apple Silicon, [Homebrew](https://brew.sh), [Ollama](https://ollama.com/download), [Claude Code](https://claude.com/claude-code).

```bash
git clone https://github.com/VladPolyakov-art/claude-jarvis.git && cd claude-jarvis
./install.sh
```

Скрипт ставит зависимости и модель Ollama, прописывает хуки в `~/.claude/settings.json` (с бэкапом), собирает `~/Applications/Jarvis.app` и включает его автозапуск при входе. Первый запуск качает модели (~2 ГБ).

Затем дай Jarvis доступы в «Системные настройки → Конфиденциальность и безопасность»: **Микрофон**, а для хоткея — **Универсальный доступ** и **Мониторинг ввода**.

## Как с ним говорить

| Ситуация | Что делает Jarvis |
|---|---|
| Claude закончил шаг | «Чат „Название“. Сделал то-то.» Если есть вопрос — задаёт его и ждёт ответ 30 с. Если вопроса нет — 6 с слушает, вдруг тебе есть что добавить |
| Claude просит посмотреть | Присылает пуш (клик открывает ссылку) и говорит: «Сходи глянь: …» |
| Карточка с вариантами | Зачитывает варианты. Отвечай «второй», «как советуешь» или своими словами. «Руками» — ответишь на экране |
| Нужно разрешение | Присылает пуш и говорит: «Клоду нужно твоё разрешение» |

**Голосовые команды** (в ответ на вопрос или после ⌃⌥J):

| Скажи | Что будет |
|---|---|
| «Стоп», «Джарвис, стоп», «отбой», «ничего», «потом» | Ничего не передаёт |
| «Чат Джарвис, добавь кнопку…» / «Передай в Interview Coach, что…» | Откладывает фразу в названный чат и передаёт её, когда тот закончит шаг. Текущий чат её не получит |
| «Переключись на чат Кики» | Спросит, что передать в этот чат |
| «Какие чаты ждут?» | Перечислит чаты, которые видел, и у кого есть отложенные сообщения |
| «Джарвис, помолчи» / «включись» | Выключает и включает Jarvis |

Чаты Jarvis называет так же, как они названы в приложении Claude. Названия можно произносить по-русски, даже если они написаны латиницей. Все сессии говорят по очереди.

## Меню-бар

Иконка показывает состояние: 🎙 жду · 🗣 говорю · 👂 слушаю · 💭 думаю · 🔇 выключен. Цифра рядом — сколько чатов стоят в очереди или ждут отложенных сообщений. В меню: включить/выключить, «Сказать первым», список чатов, выбор голоса, лог.

## Команды

```bash
./jarvis.sh app              # запустить приложение (обычно стартует само)
./jarvis.sh off | on         # выключатель: off — хуки молчат
./jarvis.sh status
./jarvis.sh say "текст"
./jarvis.sh voice eugene     # голос: aidar · eugene · aidar-low · eugene-low · baya · kseniya · xenia · piper:dmitri · piper:denis · piper:ruslan
./jarvis.sh get-piper        # скачать голоса Piper
./jarvis.sh test             # голос → микрофон → распознавание
./jarvis.sh install-hooks | uninstall-hooks
./scripts/make_app.sh [--remove]
```

Если Jarvis не запущен, хуки сразу молча выходят — Claude работает как обычно.

Настройки через переменные окружения: `JARVIS_MODEL`, `JARVIS_HOTKEY`, `JARVIS_ANSWER_TIMEOUT` (30), `JARVIS_FOLLOWUP` (6; 0 — не слушать без вопроса), `JARVIS_SILENCE` (1.6 — пауза, после которой фраза считается законченной).

## Устройство

```
Claude Code ─hook─▶ hooks/jarvis_hook.py ─HTTP─▶ Jarvis.app (:8765)
                                                   ├─ app.py       иконка в меню-баре (rumps)
                                                   ├─ daemon.py    очередь диалогов, команды, маршрутизация по чатам
                                                   ├─ sessions.py  чаты: название из приложения, отложенные сообщения
                                                   ├─ brain.py     Ollama: пересказ, вопрос, «глянь», разбор команд
                                                   └─ voice.py     Silero/Piper TTS · Silero VAD · mlx-whisper
Ответ хуку:  Stop → decision=block + reason (Claude продолжает с твоим ответом)
             PreToolUse(AskUserQuestion) → updatedInput.answers
```

Логи: `~/.jarvis/jarvis.log`.

## Ограничения

- В чат, который уже закончил работу и просто стоит, Jarvis сам написать не может. Фраза для такого чата ждёт, пока он снова закончит шаг; диктовка без названия чата кладётся в буфер обмена.
- Вопрос из нижней панели десктоп-приложения (кнопки под ответом) Jarvis не видит — только вопросы в тексте ответа и карточки с вариантами.
- Подряд Claude продолжает работу через Stop-хук не больше 8 раз (ограничение Claude Code).

## Грабли, на которые уже наступили

- MLX держит GPU-стрим в том потоке, где загружена модель, поэтому Whisper живёт в одном выделенном потоке (иначе ошибка «There is no Stream(gpu…)»).
- Silero не читает цифры и латиницу. `voice.speakable()` переводит числа в слова, латиницу в кириллицу, «+» (у Silero это знак ударения) — в слово «плюс».
- Маленькая модель додумывает. Поэтому ссылку для «глянь» берём из исходного текста, вопрос ищем только там, где есть «?», а при разборе команд модель только классифицирует фразу — передаётся она дословно.
- Whisper на тишине выдумывает «Продолжение следует…». От этого защищают VAD и фильтр.
